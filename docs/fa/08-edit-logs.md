# Edit، لاگ، حذف، عیب‌یابی

وقتی تونل از قبل ساخته شده و یا وصل نمی‌شود، این منوها را لازم داری.

---

## نقشهٔ سریع منوها

| می‌خواهم … | منو | توضیح |
|:---|:---:|:---|
| پورت / upstream / transport را عوض کنم | **3** Edit | ویرایش سرویس یا chain |
| یک سرویس را پاک کنم | **4** Remove | کل نصب پاک نمی‌شود |
| ببینم چه سرویس‌هایی دارم | **5** List | نام، آدرس، نقش |
| gost را روشن/خاموش کنم | **6** Service | مثل systemctl |
| بفهمم چرا قطع است | **7** Logs | لاگ زنده و Debug |
| محدودیت سرعت / API / JSON خام | **8** Advanced | [13](13-edit-advanced.md) |
| همه‌چیز را از سرور پاک کنم | **9** Uninstall | [13](13-edit-advanced.md) |

## Edit (`3`) چه چیزهایی را عوض می‌کند؟

معمولاً:

- نام سرویس و آدرس listen  
- نوع handler و listener  
- metadata مثل UDP، BIND، path، tunnel id  
- کاربر/رمز (auth)  
- forwarder / target  
- در chain: آدرس upstream، connector، dialer، auth  

اگر handler را به **masque** تغییر بدهی، اسکریپت listener را به **http3 + enableDatagrams** اجبار می‌کند.

بعد از Edit معمولاً سرویس را Restart کن (`6`).

## Logs (`7`) را چطور برای مبتدی استفاده کنم؟

1. گزینهٔ لاگ زنده را باز کن  
2. از کلاینت یک اتصال تست بگیر  
3. خطهای جدید را بخوان  

| اگر در لاگ دیدی | معنی ساده |
|:---|:---|
| `timeout` / `i/o timeout` | به B نمی‌رسد؛ IP، پورت، فایروال |
| `connection refused` | روی مقصد چیزی listen نیست |
| `auth` / authentication | یوزر/پس اشتباه |
| `unknown handler` | باینری قابلیت را ندارد (مثلاً masque) |
| `270` در MASQUE | معمولاً باینری بدون پچ |
| `malformed HTTP` | پروتکل کلاینت با handler جور نیست |

### Debug موقت

1. منو `7` → سطح لاگ را Debug کن  
2. مشکل را یک‌بار تکرار کن  
3. حتماً برگردان به Info (لاگ زیاد سیستم را شلوغ می‌کند)

## چک‌لیست وقتی «وصل نمی‌شود»

به ترتیب برو؛ از بالا به پایین:

| # | سؤال | چطور چک کنم؟ |
|:---:|:---|:---|
| 1 | سرویس در List هست؟ | منو `5` |
| 2 | سرویس gost فعال است؟ | منو `6` یا `systemctl is-active gost` |
| 3 | فایروال درست است؟ | TCP برای MWSS · **UDP** برای MASQUE |
| 4 | سمت B اول ساخته و بالاست؟ | روی B هم List/Status |
| 5 | transport و path یکی است؟ | Edit یا List دو طرف |
| 6 | کلاینت به پورت **A** وصل است؟ | نه به پورت Upstream روی B |
| 7 | Target از دید B درست است؟ | معمولاً `127.0.0.1:پورت پنل` |
| 8 | باینری MASQUE پچ دارد؟ | فقط اگر سناریو MASQUE است |

## Remove در مقابل Uninstall

| | Remove (`4`) | Uninstall (`9`) |
|:---|:---|:---|
| چه پاک می‌شود؟ | یک سرویس (و گاهی chain مرتبط) | تقریباً کل Wild GOST |
| کانفیگ بقیه؟ | می‌ماند | `/etc/gost` پاک می‌شود |
| باینری؟ | می‌ماند | پاک می‌شود |
