# کدام تونل را انتخاب کنم؟

به زبان ساده:

| نیازت | برو به | توضیح یک‌خطی |
|:---|:---|:---|
| رد شدن از فیلتر؛ IP خارج دیده نشود | **Anti-Filter** (`2 → 1`) | نود خارج به ایران وصل می‌شود |
| کلاینت به ایران وصل شود، خروجی از خارج + سنایی روی خارج | **Entry + Upstream** (`2 → 3` و `2 → 2`) | تونل دو سرور کلاسیک |
| همان دو سرور ولی روی HTTP/3 (UDP) | **MASQUE** | Upstream نوع MASQUE + Entry با transport MASQUE |
| فقط یک سرور، SOCKS یا HTTP | **Proxy** (`2 → 5`) | ساده‌ترین حالت |
| فقط پورت را جابه‌جا کن | **Local forward** (`2 → 6`) | مثلاً `:8080` → کامپیوتر داخل شبکه |
| چند کشور / چند پورت روی ایران | **Entry multi** (`2 → 4`) | چند B یا چند listen |

## دو نقش مهم در تونل دو سرور

```text
کلاینت  -->  Server A (ایران، Entry)  -->  تونل  -->  Server B (خارج، Upstream)  -->  هدف (مثلاً سنایی)
```

- **A:** جایی که کاربر وصل می‌شود  
- **B:** جایی که ترافیک خارج می‌شود / پنل سنایی است  

همیشه اول **B** را بساز، بعد **A**.
