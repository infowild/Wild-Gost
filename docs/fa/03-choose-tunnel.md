# کدام تونل را انتخاب کنم؟

این صفحه فقط کمک می‌کند **قبل از ساخت** بدانی کدام منو را بزنی. جزئیات هر سناریو در لینک پایین همان ردیف است.

## جدول تصمیم برای مبتدی

| نیاز من چیست؟ | برو به این منو | راهنمای کامل |
|:---|:---|:---|
| می‌خواهم از فیلتر رد شوم و IP خارج دیده نشود؛ نود خارج به ایران وصل شود | `2 → 1` Anti-Filter | [04 Anti-Filter](04-antifilter.md) |
| کلاینت به سرور ایران وصل شود، ولی ترافیک از سرور خارج بیرون برود (مثلاً سنایی روی خارج) | `2 → 2` Upstream روی خارج، بعد `2 → 3` Entry روی ایران | [05 MWSS](05-remote-forward.md) |
| همان دو سرور، ولی حمل روی HTTP/3 (UDP) | همان مسیر بالا با transport **MASQUE** | [06 MASQUE](06-masque.md) |
| چند پورت یا چند کشور (چند Server B) روی ایران | `2 → 4` Entry multi | [09 Multi-entry](09-multi-entry.md) |
| فقط یک سرور دارم؛ می‌خواهم SOCKS یا HTTP بدهم | `2 → 5` Proxy | [07](07-proxy-local-reverse.md) و [14](14-proxy-types.md) |
| فقط می‌خواهم یک پورت را به آدرس دیگری بفرستم | `2 → 6` Local forward | [07](07-proxy-local-reverse.md) |
| دستگاه پشت مودم/NAT است و باید به سرور عمومی وصل شود | `2 → 7` Reverse (برای ضد فیلتر ایران ترجیحاً Anti-Filter) | [07](07-proxy-local-reverse.md) |
| DNS یا TUN یا سایت فایل یا redirect شفاف | `2 → 8` More | [10](10-dns-tun-file-redirect.md) |

## تصویر ذهنی تونل دو سرور

```text
گوشی / کلاینت
      │
      │  وصل می‌شود به پورت عمومی A
      ▼
┌──────────────────┐
│ Server A (Entry) │   معمولاً ایران
│ گوش می‌دهد       │
└────────┬─────────┘
         │  تونل رمزشده (مثلاً MWSS یا MASQUE)
         ▼
┌──────────────────┐
│ Server B (Upstream)│  معمولاً خارج
│ خروج / پنل       │
└────────┬─────────┘
         │
         ▼
   127.0.0.1:8080
   (مثلاً سنایی روی همان B)
```

### معنی هر کلمه برای مبتدی

| کلمه | معنی |
|:---|:---|
| **Entry** | در ورودی؛ جایی که کلاینت می‌زند |
| **Upstream** | سمت بالا / خروج تونل |
| **Target** | مقصد نهایی بعد از تونل؛ اغلب `127.0.0.1:پورت پنل` روی B |
| **Transport** | «لباس» اتصال بین A و B (MWSS، TLS، MASQUE و …) |
| **Handler** | نوع سرویس روی listen (مثل relay یا masque) |

## Anti-Filter با Entry+Upstream چه فرقی دارد؟

| | Anti-Filter | Entry + Upstream |
|:---|:---|:---|
| جهت تونل کنترل | خارج → ایران (ریورس) | ایران/Entry → خارج (فوروارد) |
| کاربر چه می‌بیند؟ | معمولاً فقط دامنه/IP ایران | IP یا دامنهٔ Entry (اغلب ایران) |
| پیچیدگی | بیشتر (SNI، decoy، Tunnel ID) | ساده‌تر برای سنایی روی خارج |
| کی انتخابش کنم؟ | تمرکز روی استتار و ریورس | Remote Port Forward کلاسیک |

## ترتیب درست کار (خیلی مهم)

1. روی **هر دو** سرور Install را انجام بده  
2. اول **Server B** را بساز (Upstream یا Foreign node)  
3. بعد **Server A** را بساز (Entry یا Iran panel)  
4. فایروال پورت درست را باز کن (TCP یا UDP)  
5. با List و Logs چک کن  

اگر اشتباه انتخاب کردی نگران نباش: با Remove همان سرویس را پاک کن و سناریوی درست را از نو بساز.
