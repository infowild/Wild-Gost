# نصب و به‌روزرسانی باینری

روی **هر سرور** (ایران و خارج) یک‌بار باید باینری `gost` نصب شود. بدون آن منو کار می‌کند ولی تونل راه نمی‌افتد.

## باز کردن نصب

```bash
sudo wild gost
```

سپس گزینهٔ **`1) Install / Update`** را بزن.

اگر هنوز اسکریپت را نداری:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/infowild/Wild-Gost/master/gost.sh)
```

---

## چهار کانال نصب — کدام را بزنم؟

| گزینه | نام | چه چیزی نصب می‌شود؟ | برای چه کسی؟ |
|:---:|:---|:---|:---|
| **1** | Stable | آخرین نسخهٔ پایدار از GitHub | کار عادی با MWSS / Relay / Proxy — **نه** MASQUE جدی |
| **2** | Nightly | نسخهٔ شبانه؛ masque معمولاً ثبت شده | تست؛ TCP CONNECT ممکن است هنوز خراب باشد |
| **3** | Build patched | از سورس می‌سازد و پچ MASQUE را اعمال می‌کند | **پیشنهادی برای تونل MASQUE** (نیاز به دانلود Go) |
| **4** | Local binary | فایل آماده روی دیسک را کپی می‌کند | وقتی ایران نمی‌تواند Go/GitHub را خوب دانلود کند |

### معنی ساده

- می‌خواهی تونل معمولی MWSS بزنی → معمولاً **1 Stable** کافی است.  
- می‌خواهی MASQUE (HTTP/3) پایدار کار کند → **3** روی خارج، و اگر لازم شد **4** روی ایران.  
- Update با **1** روی سروری که قبلاً پچ MASQUE داشته، باینری را عوض می‌کند و MASQUE ممکن است بشکند.

---

## مسیر پیشنهادی برای MASQUE (ایران مشکل دانلود دارد)

### روی Server B (خارج)

1. منو → `1` Install  
2. گزینهٔ **`3` Build patched**  
3. صبر کن تا بیلد تمام شود  

باینری نهایی معمولاً اینجاست:

```text
/usr/local/bin/gost
```

### کپی به ایران

از کامپیوتر خودت یا از خود Server B:

```bash
scp /usr/local/bin/gost root@IP_ایران:/tmp/gost-masque-fixed
```

### روی Server A (ایران)

1. منو → `1` Install  
2. گزینهٔ **`4` Local binary**  
3. مسیر را بزن: `/tmp/gost-masque-fixed` (یا Enter اگر پیش‌فرض همین باشد)

---

## بعد از نصب موفق چه می‌بینی؟

- دستور `gost -V` نسخه را نشان می‌دهد  
- منو با `sudo wild gost` باز می‌شود  
- سرویس systemd به نام `gost` ساخته می‌شود  

در حالت Iran، اسکریپت برای لینک‌های GitHub از mirror استفاده می‌کند تا دانلود راحت‌تر شود.

## خطاهای رایج

| مشکل | علت محتمل | کار |
|:---|:---|:---|
| دانلود Go شکست خورد | فیلتر / قطعی `go.dev` و بعضی mirrorها | بیلد روی خارج + گزینهٔ 4 روی ایران |
| `unknown handler: masque` | باینری قدیمی / Stable | گزینهٔ 3 یا 4 پچ‌شده |
| MASQUE بعد از Update خراب شد | Stable روی پچ نصب شد | دوباره 3 یا 4 |
