# Anti-Filter (ریورس ایران)

برای عبور از فیلتر: سرور خارج به ایران **وصل می‌شود** (نه برعکس). کاربر فقط دامنه/IP ایران را می‌بیند.

```text
کاربر ──SNI/Host──► ایران :443 (entrypoint)
                        │
نود خارج ──تونل──► ایران :پورت‌کنترل ──► 127.0.0.1:سنایی روی خارج
```

## مراحل منو

| مرحله | کجا | مسیر |
|:---|:---|:---|
| ۱ | ایران | `2 → 1 → 1` Iran panel |
| ۲ | خارج | `2 → 1 → 3` Foreign node (همان Tunnel ID) |
| ۳ | اختیاری | `2 → 1 → 2` نود بیشتر با hostname جدا |

## نکات ساده

- چند نود با **hostname / SNI** جدا می‌شوند (نه path مثل `/trk01`)  
- Transport دو طرف یکی باشد (پیش‌فرض MWSS)  
- Decoy روی `:80` صفحهٔ عادی نشان می‌دهد  
- وضعیت در `/etc/gost/wild-antifilter.json`  
- entrypoint برای VLESS خام بدون TLS معمولاً مناسب نیست؛ یا TLS+SNI روی کلاینت/سنایی، یا سناریوی Entry ساده
