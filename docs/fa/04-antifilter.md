# Anti-Filter (ریورس ایران)

## این سناریو چیست؟

در مدل عادی، کلاینت به سرور خارج وصل می‌شود. در **Anti-Filter** برعکس است:

- سرور **خارج** خودش به سرور **ایران** وصل می‌شود (ریورس)  
- کاربر فقط دامنه یا IP **ایران** را می‌بیند  
- مسیریابی بین چند نود با **Hostname / SNI** است، نه با path مثل `/us`

```text
کاربر
  │  SNI / Host  (مثلاً us.example.com)
  ▼
ایران :443   ←  entrypoint کاربران
  │
  ├── decoy اختیاری روی :80  (سایت معمولی برای اسکنر)
  │
  └── پورت کنترل تونل
        ▲
        │  نود خارج dial می‌کند
        │
     سرور خارج  ──►  127.0.0.1:پورت پنل روی خارج
```

State پنل در این فایل ذخیره می‌شود:

```text
/etc/gost/wild-antifilter.json
```

---

## پیش‌نیاز

- دامنه که DNS آن به IP ایران اشاره کند (برای TLS و SNI معمولاً لازم است)  
- Install روی ایران و خارج  
- پورت‌های کنترل و entry روی فایروال ایران باز باشند  

---

## مرحله ۱ — روی ایران: Iran panel

مسیر منو:

```text
2) Add  →  1) Anti-Filter  →  1) Iran panel
```

ویزارد معمولاً این‌ها را می‌پرسد:

| سؤال | معنی برای مبتدی |
|:---|:---|
| دامنه | دامنه‌ای که کاربر/SNI با آن می‌آید |
| پورت کنترل تونل | پورتی که نود خارج به آن dial می‌کند |
| پورت entry | معمولاً 443 برای کاربر |
| Transport | لباس تونل بین خارج و ایران (پیش‌فرض اغلب MWSS) |
| Decoy روی 80؟ | صفحهٔ فیک برای پروب‌ها |
| نود اول | نام + hostname/SNI + هدف روی خارج |

در پایان یک **Tunnel ID** و دستور/نکته برای نود خارج می‌گیری. آن را نگه دار.

---

## مرحله ۲ — روی خارج: Foreign node

```text
2) Add  →  1) Anti-Filter  →  3) Foreign node
```

| فیلد | توضیح |
|:---|:---|
| آدرس ایران | `IP_ایران:پورت_کنترل` |
| Tunnel ID | همان مقدار ساخته‌شده روی ایران |
| Transport / path | باید با پنل ایران یکی باشد |
| Target | معمولاً `127.0.0.1:پورت سنایی` روی همین خارج |

---

## مرحله ۳ — نود بیشتر (اختیاری)

روی ایران:

```text
2 → 1 → 2) Add node to panel
```

هر نود hostname جدا می‌گیرد، مثلاً:

- `us.example.com`  
- `de.example.com`  

کاربر با تغییر SNI/Host بین نودها جابه‌جا می‌شود، نه با عوض کردن path در URL.

## نکات مهم برای مبتدی

1. Transport دو طرف **یکی** باشد.  
2. برای WS/WSS/MWSS مقدار **path** دو طرف یکی باشد.  
3. ورود خام VLESS بدون TLS به entrypoint معمولاً خطا می‌دهد (`malformed HTTP`). یا از TLS+SNI استفاده کن، یا سناریوی Entry ساده ([05](05-remote-forward.md)).  
4. اگر شک داری، Doctor را اجرا کن و خروجی را بخوان.
