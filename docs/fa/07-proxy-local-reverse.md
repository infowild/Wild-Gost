# پروکسی، فوروارد محلی، Reverse

این سه گزینه زیر منوی Add هستند و هر کدام کار متفاوتی می‌کنند. با تونل دو سرور قاطی‌شان نکن.

---

## ۱) Proxy تک‌سروره — `2 → 5`

### چیست؟

روی **همین یک سرور** یک سرویس پروکسی می‌سازی. کلاینت مستقیم به همین سرور وصل می‌شود. Server دوم لازم نیست.

### چه نوع‌هایی دارد؟

لیست کامل انواع: [14 انواع Proxy](14-proxy-types.md)

رایج‌ترین‌ها برای مبتدی:

| نوع | مثال اتصال کلاینت |
|:---|:---|
| SOCKS5 | `socks5://IP_SERVER:1080` |
| HTTP | `http://IP_SERVER:8080` |
| Shadowsocks | با method و password در کلاینت SS |

### مراحل کلی

1. `2 → 5` Proxy  
2. نوع را انتخاب کن  
3. پورت listen را بزن  
4. اگر خواست transport/listener جدا بپرسد، جواب بده  
5. اگر **MASQUE** انتخاب کنی، listener خودکار **http3** می‌شود و فایروال باید UDP باشد  

### کی Proxy؟ کی Upstream+Entry؟

| وضعیت | انتخاب |
|:---|:---|
| فقط یک سرور خارج دارم و می‌خواهم پروکسی بدهم | Proxy |
| ایران + خارج و سنایی روی خارج | Upstream + Entry |

## ۲) Local port forward — `2 → 6`

### چیست؟

فقط پورت را از یک جا به یک آدرس دیگر می‌فرستد. تونل بین‌الملل نیست.

```text
گوش دادن روی این سرور :8080
        │
        ▼
  192.168.1.10:80   (یک دستگاه در شبکه داخلی)
```

### مثال کاربرد

- می‌خواهی از بیرون به یک وب‌سرور داخلی برسی ولی فقط این ماشین IP عمومی دارد  
- می‌خواهی پورت پنل را روی پورت دیگری publish کنی  

### مراحل

1. `2 → 6`  
2. پورت listen  
3. آدرس هدف (`IP:port`)  
4. TCP یا UDP  

---

## ۳) Reverse عمومی — `2 → 7`

### چیست؟

برای وقتی یک دستگاه پشت NAT/مودم است و نمی‌تواند مستقیم از اینترنت listen کند؛ به یک سرور عمومی وصل می‌شود و تونل ریورس می‌سازد (tunnel / rtcp / rudp).

### برای ضد فیلتر ایران چه کنم؟

اگر هدفت عبور از فیلتر با مدل ایران‌محور است، به‌جای این گزینه از wizard مخصوص استفاده کن:

```text
2 → 1) Anti-Filter
```

راهنما: [04 Anti-Filter](04-antifilter.md)

`2 → 7` بیشتر برای ریورس عمومی/پیشرفته است، نه جایگزین کامل Anti-Filter.
