# منوی اسکریپت چیست؟

بعد از نصب، پنل را این‌طور باز می‌کنی:

```bash
sudo wild gost
```

این یک منوی متنی روی سرور لینوکس است. کارش این است که به‌جای ویرایش دستی فایل JSON، با سؤال‌وپاسخ سرویس و تونل بسازی.

فایل واقعی کانفیگ همیشه این است:

```text
/etc/gost/config.json
```

اسکریپت همان فایل را می‌نویسد و سرویس `gost` را با systemd مدیریت می‌کند.

---

## منوی اصلی (۰ تا ۹)

| گزینه | نام | یعنی چه؟ | چه زمانی استفاده کنم؟ |
|:---:|:---|:---|:---|
| **1** | Install / Update | باینری برنامه `gost` و خود اسکریپت مدیریت را نصب یا عوض می‌کند | اولین بار روی هر سرور؛ یا وقتی می‌خواهی نسخه را عوض کنی |
| **2** | Add | سرویس / تونل جدید می‌سازد | ساخت Anti-Filter، Upstream، Entry، Proxy و … |
| **3** | Edit | چیزهای موجود را عوض می‌کند (پورت، upstream، transport، رمز و …) | وقتی کانفیگ را اشتباه زدی یا باید تغییر بدهی |
| **4** | Remove | فقط **یک** سرویس را پاک می‌کند | حذف یک تونل بدون پاک کردن کل نصب |
| **5** | List | لیست سرویس‌های فعلی را نشان می‌دهد | دیدن نام، پورت، نقش هر سرویس |
| **6** | Service | Start / Stop / Restart / Status | روشن/خاموش کردن موتور `gost` |
| **7** | Logs | لاگ زنده، خطا، سطح Debug، بررسی صحت کانفیگ | وقتی وصل نمی‌شود و باید علت را ببینی |
| **8** | Advanced | Bypass، Admission، Limiter، API، Metrics، JSON خام | تنظیمات پیشرفته و محدودیت‌ها |
| **9** | Uninstall | تقریباً همه‌چیز مربوط به Wild GOST را پاک می‌کند | حذف کامل از سرور |
| **0** | Exit | خروج از منو | تمام شدن کار |

## منوی Add (`2`) — مهم‌ترین بخش

اینجا نوع کار را انتخاب می‌کنی:

| گزینه | نام | توضیح ساده برای مبتدی | معمولاً روی کدام سرور؟ |
|:---:|:---|:---|:---|
| **1** | Anti-Filter | مدل «ریورس»: سرور خارج به ایران وصل می‌شود. کاربر فقط ایران را می‌بیند | ایران = پنل · خارج = نود |
| **2** | Upstream | سمت خروج تونل دو سرور (Server B) | سرور خارج |
| **3** | Entry single | سمت ورود تونل؛ یک پورت برای کلاینت (Server A) | معمولاً ایران |
| **4** | Entry multi | چند پورت یا چند کشور روی یک Entry | معمولاً ایران |
| **5** | Proxy | SOCKS / HTTP / Shadowsocks و … روی **همین** سرور | هر سرور، تک‌هاست |
| **6** | Local forward | فقط پورت را جابه‌جا می‌کند (مثلاً `:8080` → یک IP داخلی) | همان ماشین/شبکه |
| **7** | Reverse | ریورس عمومی (tunnel / rtcp / rudp) بدون wizard ضد فیلتر | وقتی دستگاه پشت NAT است |
| **8** | More | DNS، TUN/TAP، فایل استاتیک، Redirect شفاف | موارد خاص |

## دو نقش خیلی مهم: A و B

در تونل دو سرور کلاسیک:

```text
کلاینت  -->  Server A (Entry، معمولاً ایران)  -->  تونل  -->  Server B (Upstream، خارج)  -->  هدف
```

- **A (Entry):** جایی که کاربر به آن وصل می‌شود  
- **B (Upstream):** جایی که ترافیک خارج می‌شود یا پنل (مثل سنایی) روی آن است  

**قانون مبتدی:** همیشه اول B را بساز، بعد A را.
