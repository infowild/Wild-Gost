# تونل MASQUE (HTTP/3)

MASQUE ترافیک را روی **HTTP/3 / QUIC (UDP)** حمل می‌کند. هم TCP و هم UDP را پشتیبانی می‌کند؛ سناریوی سنایی معمولاً **TCP** است.

```text
کلاینت --> A:8080 --> masque + h3-masque --> B:9443/udp (masque+http3) --> 127.0.0.1:8080
```

## باینری لازم

Stable قدیمی (`≤3.2.6`) ماسک ندارد. برای TCP CONNECT پایدار:

- Install → **3** (بیلد پچ) روی سرور خارج  
- روی ایران اگر Go دانلود نشد → Install → **4** با فایل `scp` شده از خارج  

## گام ۱ — Server B

1. `2 → 2` Upstream  
2. Handler: **4) MASQUE**  
3. پورت مثلاً `9443`  
4. اسکریپت listener را **http3** می‌گذارد (نه `h3`)  

فایروال: **UDP** همان پورت باز باشد.

## گام ۲ — Server A

1. `2 → 3` Entry single  
2. Listen مثلاً `8080` / TCP  
3. Transport: **11) MASQUE**  
4. Upstream: `IP_B:9443`  
5. Target: `127.0.0.1:8080`

## هشدارهای مهم

| اشتباه | درست |
|:---|:---|
| listener نوع `h3` | باید **`http3`** باشد (`h3` = PHT و برای MASQUE غلط است) |
| باینری بدون پچ | ممکن است خطای H3 `270` بگیری |
| فقط TCP فایروال | MASQUE روی **UDP** است |

`curl` به سنایی جواب خالی می‌دهد؛ طبیعی است. موفقیت = لاگ `connect-tcp` روی B.

امنیت: کانال با TLS داخل QUIC رمز می‌شود؛ وضعیت قابلیت در GOST هنوز Alpha است. شناسایی‌پذیری شبیه HTTP/3 است؛ عبور از فیلتر تضمینی نیست.
