# تونل MASQUE (HTTP/3)

## MASQUE چیست؟ (برای مبتدی)

MASQUE ترافیک را روی **HTTP/3** حمل می‌کند. HTTP/3 روی پروتکل **QUIC** است و QUIC روی **UDP** کار می‌کند.

یعنی برخلاف MWSS که معمولاً TCP است، اینجا فایروال باید **UDP** باز باشد.

منطق تونل همان Remote Port Forward است:

```text
کلاینت → A:8080 → (masque + h3-masque) → B:9443/UDP → 127.0.0.1:8080
```

| قطعه | معنی |
|:---|:---|
| `masque` | نوع handler/connector |
| `http3` | نوع listener سمت B (**نه** `h3`) |
| `h3-masque` | dialer سمت A |

> `h3` در GOST چیز دیگری است (PHT). برای MASQUE حتماً `http3` باشد. اسکریپت این را اجباری می‌کند.

---

## باینری لازم

نسخه‌های Stable قدیمی (`≤ 3.2.6`) اغلب اصلاً masque ندارند.  
برای TCP CONNECT پایدار باید باینری **پچ‌شده** باشد.

| سرور | کار پیشنهادی |
|:---|:---|
| خارج (B) | Install → **3 Build patched** |
| ایران (A) | اگر Go دانلود نشد: باینری را از B با `scp` بگیر → Install → **4** |

جزئیات نصب: [02](02-install.md)

**هشدار:** بعداً Update با Stable نزن؛ پچ پاک می‌شود و خطای H3 مثل `270` برمی‌گردد.

---

## گام ۱ — Server B: Upstream از نوع MASQUE

```text
2) Add  →  2) Upstream
```

| فیلد | مقدار پیشنهادی | چرا |
|:---|:---|:---|
| Handler | **4) MASQUE** | سرویس MASQUE |
| Port | مثلاً `9443` | هر پورت آزاد UDP |
| Listener | اسکریپت می‌گذارد **http3** | اجباری و درست |

فایروال B:

```text
UDP 9443  (یا پورتی که زدی)  ←  باز باشد
```

---

## گام ۲ — Server A: Entry با transport MASQUE

```text
2) Add  →  3) Entry single
```

| فیلد | مقدار پیشنهادی |
|:---|:---|
| Listen | مثلاً `8080` (TCP برای کلاینت) |
| Transport | **11) MASQUE** |
| Upstream | `IP_عمومی_B:9443` |
| Target | `127.0.0.1:8080` (سنایی روی B) |

وقتی transport را MASQUE بگیری، اسکریپت connector را `masque` و dialer را `h3-masque` می‌کند.

همین منطق در **Multi-entry** (`2 → 4`) هم کار می‌کند؛ فقط همهٔ Bها باید Upstream MASQUE داشته باشند.

## جدول اشتباهات رایج

| اشتباه | نتیجه | درست |
|:---|:---|:---|
| listener نوع `h3` | تونل غلط / خطا | `http3` |
| فقط TCP در فایروال باز است | وصل نمی‌شود | UDP همان پورت |
| باینری بدون پچ | خطای H3 `270` | Install 3 یا 4 پچ‌شده |
| Stable بعد از پچ | دوباره می‌شکند | برای MASQUE Stable نزن |
| Target را IP ایران گذاشتی | ترافیک به جای غلط می‌رود | Target از دید B |

## چطور بفهمم کار کرد؟

- روی B در Logs چیزی شبیه `connect-tcp` می‌بینی  
- `curl` به پورت سنایی ممکن است جواب خالی بدهد؛ برای VLESS طبیعی است  
- کلاینت واقعی (مثلاً v2rayN) به `IP_A:8080` وصل می‌شود  

اگر نشد، چک‌لیست [08](08-edit-logs.md) را برو.

## امنیت و انتظارات واقعی

- کانال داخل QUIC با TLS رمز می‌شود  
- در GOST وضعیت قابلیت هنوز در سطح Alpha مطرح شده  
- ظاهر ترافیک شبیه HTTP/3 است؛ **عبور از فیلتر را تضمین نمی‌کند**
