# تونل دو سرور (MWSS)

```text
Client → A:8080 → MWSS → B:2018 (Relay) → 127.0.0.1:8080
```

## B (خارج) — `2 → 2`

| فیلد | نمونه |
|:---|:---|
| Handler | Relay |
| Transport | MWSS |
| Port | `2018` / `443` |
| Path | `/ws` (دو طرف یکی) |

## A (ایران) — `2 → 3`

| فیلد | نمونه |
|:---|:---|
| Listen | `8080` (TCP) |
| Transport / path | همان B |
| Upstream | `IP_B:2018` |
| Target | `127.0.0.1:8080` (از دید B) |

| قانون | |
|:---|:---|
| ترتیب | اول B، بعد A |
| کلاینت | فقط پورت A |
| آدرس B | IP عمومی مطمئن‌تر از دامنهٔ اشتباه |
