# Entry چند پورت / چند لوکیشن

## این منو برای چیست؟

مسیر:

```text
2) Add  →  4) Entry multi-port / multi-location
```

وقتی روی Server A (معمولاً ایران) می‌خواهی:

- چند پورت listen داشته باشی، یا  
- به چند Server B وصل شوی (مثلاً یکی آمریکا، یکی آلمان)

به‌جای چند بار زدن Entry single، یک wizard گروهی می‌سازد.

---

## پیش‌نیاز

1. روی **هر** Server B از قبل Upstream ساخته باشی  
2. Transport همهٔ آن‌ها با چیزی که در multi انتخاب می‌کنی یکی باشد  
3. اگر MASQUE است: همه Bها `masque+http3` و UDP باز  

---

## ویزارد چه می‌پرسد؟ (به زبان ساده)

### ۱) نام گروه

یک اسم برای مجموعه، مثلاً `iran-multi`. در metadata و نام سرویس‌ها استفاده می‌شود.

### ۲) TCP یا UDP

برای پنل سنایی معمولاً **TCP**.

### ۳) Connector

| گزینه | کی؟ |
|:---|:---|
| relay | با Upstream از نوع Relay / MWSS |
| socks5 / http | اگر سمت B همان handler را دارد |
| (خودکار) masque | اگر transport را MASQUE بگیری، اسکریپت اجبار می‌کند |

### ۴) Transport preset

مثل Entry تکی: MWSS، TLS، MASQUE و …  
اگر **11) MASQUE** بزنی → connector=`masque` و dialer=`h3-masque`.

### ۵) Locations (Server Bها)

برای هر لوکیشن:

| فیلد | مثال |
|:---|:---|
| Name | `US` |
| Address | `216.x.x.x:2018` |

می‌توانی چند تا پشت‌سرهم اضافه کنی.

### ۶) Ports

لیست با ویرگول، مثلاً:

```text
8080,8443
```

یعنی روی A این پورت‌ها پایهٔ listen هستند (بسته به Mode ممکن است جابه‌جا شوند).

### ۷) Target

دو حالت رایج:

| حالت | معنی |
|:---|:---|
| `127.0.0.1:PORT` | پورت هدف روی B = همان پورت listen (یا الگوی مرتبط) |
| یک آدرس ثابت | همه به یک target بروند، مثلاً همیشه `127.0.0.1:8080` |

یادت باشد: Target از دید **B** است.

### ۸) Mode — مهم‌ترین انتخاب

#### حالت ۱: Port per location

هر لوکیشن پورت listen جدا می‌گیرد.

فرمول ساده:

```text
listen = پورت_پایه + (شماره_لوکیشن × offset)
```

مثال: پایه `8080`، offset `10000`، دو لوکیشن US و DE:

| لوکیشن | listen روی A |
|:---|:---|
| US (اولی) | `:8080` |
| DE (دومی) | `:18080` |

کاربر با عوض کردن پورت، کشور را عوض می‌کند.

#### حالت ۲: Shared + selector

یک (یا چند) پورت مشترک؛ بین چند B با استراتژی انتخاب می‌شود:

| استراتژی | رفتار ساده |
|:---|:---|
| **fifo** | اولی را ترجیح بده تا خراب شود |
| **round** | نوبتی بین لوکیشن‌ها |
| **rand** | تصادفی |

## بعد از ساخت چه کنم؟

1. منو `5` List — برای هر سرویس listen و chain را ببین  
2. از کلاینت هر پورت را جدا تست کن  
3. اگر یک لوکیشن مرد، Logs همان سرویس/کل gost را چک کن  

---

## اشتباهات رایج

| اشتباه | نتیجه |
|:---|:---|
| B هنوز Upstream ندارد | dial fail |
| یک B با MWSS و دیگری با MASQUE | ناسازگار |
| فراموش کردن UDP برای MASQUE | فقط بعضی لوکیشن‌ها می‌میرند |
| Target را IP ایران گذاشتن | ترافیک به مقصد غلط |
