# انواع Proxy (منوی Add → Proxy)

مسیر:

```text
2) Add  →  5) Proxy
```

## این منو چه می‌سازد؟

یک سرویس پروکسی که روی **همین سرور** listen می‌کند.  
کلاینت مستقیم به IP همین سرور وصل می‌شود.

اگر هدف تو تونل دو سروره (ایران → خارج → سنایی) است، معمولاً به‌جای Proxy از **Upstream + Entry** استفاده کن: [05](05-remote-forward.md) / [06](06-masque.md).

---

## جدول انواع — کامل و به زبان ساده

| # | نوع | به زبان مبتدی | مثال استفاده |
|:---:|:---|:---|:---|
| 1 | **SOCKS5** | پروکسی همه‌کاره؛ خیلی از کلاینت‌ها پشتیبانی می‌کنند | مرورگر، تلگرام، ابزارها با `socks5://IP:1080` |
| 2 | **SOCKS4** | نسخه قدیمی‌تر SOCKS | کلاینت‌های قدیمی |
| 3 | **HTTP** | پروکسی HTTP کلاسیک | `http://IP:8080` در تنظیمات پروکسی سیستم/مرورگر |
| 4 | **HTTP2** | همان ایده روی HTTP/2 | وقتی می‌خواهی روی h2 حمل شود |
| 5 | **HTTP3** | روی HTTP/3 | نیاز به UDP / listener مناسب |
| 6 | **Relay** | رلهٔ خود GOST | هم در تونل دو سرور به‌عنوان Upstream رایج است |
| 7 | **Shadowsocks** | پروتکل SS با method و رمز | کلاینت Shadowsocks |
| 8 | **Auto** | سعی می‌کند نوع پروتکل ورودی را خودش تشخیص دهد | وقتی مخلوط کلاینت داری |
| 9 | **SNI** | بر اساس SNI مسیر را عوض می‌کند | مسیریابی دامنه |
| 10 | **SSHD** | شبیه سرویس SSHD | سناریوهای خاص SSH |
| 11 | **MASQUE** | پروکسی MASQUE | listener اجباری `http3` · فایروال UDP |
| 12 | **Serial** | سریال / کاربری خاص | تجهیزات خاص |

---

## بعد از انتخاب نوع چه اتفاقی می‌افتد؟

ویزارد معمولاً می‌پرسد:

1. **پورت listen** — پورتی که از اینترنت/شبکه به آن وصل می‌شوند  
2. **Listener / transport** — چطور روی سیم برود (جز MASQUE که `http3` ثابت است)  
3. گاهی **auth** — یوزر و پسورد  
4. برای Shadowsocks: **method** و **password**  
5. برای SOCKS: اختیاراتی مثل UDP یا BIND  

---

## مثال‌های اتصال کلاینت

```text
socks5://203.0.113.10:1080
http://203.0.113.10:8080
```

اگر auth گذاشتی، در کلاینت همان یوزر/پس را وارد کن.

---

## نکات امنیتی برای مبتدی

1. پورت پروکسی را بی‌رمز روی اینترنت باز نگذار مگر لازم باشد.  
2. Admission در Advanced می‌تواند IPهای مجاز را محدود کند.  
3. Limiter جلوی مصرف انفجاری را می‌گیرد.  
4. برای عبور از فیلتر با دو سرور، Proxy تکی جای Entry+Upstream را نمی‌گیرد.
